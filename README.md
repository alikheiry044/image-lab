# Image Lab 🖼️

A small educational desktop app for image effects, built with Python, OpenCV and CustomTkinter.

## Setup
```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Lessons
```bash
python lessons/lesson_01_basics.py
python lessons/lesson_02_filters.py
```
